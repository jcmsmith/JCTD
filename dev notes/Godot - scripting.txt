---------------------------------------------------------------

-every script in Godot represents a class and extends one of the engine's built-in classes
-Classes (nodes) use PascalCase, variables and functions use snake_case, and constants use ALL_CAPS

-The node types your classes inherit from give you access to properties such as rotation and position
-the variables you put at the top of the file are your class's properties, also called member variables

-First-class types can be passed around as arguments directly
	-methods (https://docs.godotengine.org/en/stable/classes/class_callable.html#class-callable)
	-signals

---------------------------------------------------------------

-For occasional input checks, like jumping, use built-in input callbacks, mainly _unhandled_input()
	-https://docs.godotengine.org/en/stable/tutorials/inputs/inputevent.html#doc-inputevent

-To check for input every frame, use the Input singleton
